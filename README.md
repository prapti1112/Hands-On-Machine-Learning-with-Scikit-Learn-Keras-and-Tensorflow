# 🚀 48-Hour ML Sprint
Based on: *Hands-On Machine Learning with Scikit-Learn, Keras, and TensorFlow* (2nd Ed.)

## 📁 Structure
- `notebooks/`: Chapter-by-chapter Jupyter notebooks
- `src/`: Reusable Python modules
- `data/`: Raw & processed datasets
- `models/`: Saved model weights/checkpoints
- `outputs/`: Visualizations, logs, and reports
