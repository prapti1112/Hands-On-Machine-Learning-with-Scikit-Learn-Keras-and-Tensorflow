# Hands-On Machine Learning with Scikit-Learn, Keras, and TensorFlow, Second Edition: A Practical Guide to Building Intelligent Systems
Author: Géron, Aurélien

## Goal:
This resource serves as a comprehensive study guide for mastering machine learning fundamentals and advanced applications using Scikit-Learn, Keras, and TensorFlow, with emphasis on understanding core concepts, implementing practical solutions, and building end-to-end machine learning systems presented throughout the second edition.

## Structure
* `notebooks/`: Chapter-by-chapter implementations and exercises (Chapters 1-19)
  - 01-18: Core ML algorithms and deep learning techniques
  - 19: Model deployment strategies

* `src/`: Reusable Python modules and utility functions
* `data/`: Raw and processed datasets for hands-on exercises
* `models/`: Saved model weights and checkpoints
* `outputs/`: Generated visualizations, reports, and analysis results
